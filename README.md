# SVARA: Move Deeper

Build a frontend-only premium yoga and mindful living website called SVARA.

Use the uploaded reference image as the visual direction and design inspiration. Do NOT make a pixel-for-pixel copy. Instead, create an original website that captures the same overall feeling: sophisticated editorial wellness design, oversized typography, rounded image cards, soft neutral backgrounds, dark green typography, subtle gradients, spacious layouts, and a modern Gen-Z aesthetic.

BRAND

Brand name: SVARA

Tagline:
Move slower. Feel deeper.

Brand positioning:
SVARA is a modern yoga and mindful-living platform for people who want to reconnect with their body, mind, and everyday life.

The brand should feel:

Premium

Calm

Modern

Slightly artistic

Gen-Z but NOT childish

Spiritual without being overly “new age”

Editorial like a high-end fashion/wellness magazine

Warm and human

Minimal but visually rich

Avoid the typical yoga website look with lotus icons everywhere, overly spiritual language, purple gradients, stock wellness clichés, or generic SaaS layouts.

RESPONSIVE DESIGN

The website must be fully responsive.

Desktop:
Use editorial asymmetric layouts and large imagery.

Tablet:
Rearrange grids naturally.

Mobile:
Prioritize typography, imagery and simple scrolling.

Mobile hero should stack:
headline → image → buttons.

Course cards should become horizontally scrollable.

Navigation should become a hamburger menu.

Do not simply shrink the desktop design.

IMPORTANT FRONTEND REQUIREMENT

This is frontend only for now.

Do NOT build:

Backend

Authentication logic

Database

Payment processing

Real course purchasing

Real user accounts

Admin dashboard

API integrations

Use realistic mock data and interactions.

Buttons can navigate to placeholder/internal pages.

Create the visual foundation so backend functionality can be added later.

IMAGE DIRECTION

Photography should include:

Diverse people

Natural sunlight

Earthy interiors

Yoga mats

Outdoor movement

Calm facial expressions

Realistic environments

Editorial lifestyle compositions

Avoid:

Overly staged fitness stock photography

Extremely muscular fitness models

Fake-looking AI wellness imagery

Excessive lotus imagery

Generic meditation clichés

Images should have rounded corners consistent throughout the website.

BRAND VOICE

Copy should be short, poetic and modern.

Avoid corporate phrases like:
“Transform your wellness journey with our comprehensive solution.”

Instead write:

“Come back to yourself.”

“Move slower. Feel deeper.”

“Your body already knows the way.”

“No perfect poses. No perfect days.”

“Just practice.”

The tone should feel like a premium wellness brand speaking to a thoughtful Gen-Z audience.

TECHNICAL FRONTEND

Use:

React

TypeScript

Tailwind CSS

Modern component architecture

Reusable cards/components

Responsive design

Accessible buttons and navigation

Clean semantic HTML

Lucide icons or similarly minimal icon library

Keep components modular and easy to connect to a backend later.

Use mock data for courses, practices, articles, testimonials and instructors.

Make sure there are no broken links, overflow issues, placeholder lorem ipsum, or unfinished sections.

FINAL DESIGN GOAL

When the website loads, the first impression should be:

“This feels like a real premium yoga brand.”

Not:

“This is a yoga template.”

The visual language should be inspired by the uploaded reference's:

editorial composition

large typography

image/card structure

pill elements

green/cream palette

rounded UI

spacious layout

while creating a distinct original SVARA identity.

Prioritize visual storytelling, strong typography, beautiful photography, whitespace, and premium interactions over adding too many features.

Make the homepage feel like a brand experience first and a course-selling website second.
